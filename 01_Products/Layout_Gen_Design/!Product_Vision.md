# Product Vision: Layout Generative Design

## Strategy
Transitioning from geometric scripts to a full-featured Revit Add-in that automates site planning.

## Core Value Proposition
Reducing the time for site layout generation from days to minutes while providing quantitative evaluation of every variant.

## Target Audience
- BIM Managers
- Architects
- Urban Developers

## Key Features (MVP)
- Automated Macro-Zoning.
- Parametric Building Infill.
- Real-time Scoring & Comparison.
- Direct Export to Revit Elements.
