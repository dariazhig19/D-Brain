# Phase 04: New Groups, Generic Rules & Rule Network

## Background

Phases 01–03 placed 3 monolithic groups (Power Block, Cooling Tower, Admin Building) with 6 hand-coded rules. Phase 04 expands to **12 groups** (including polyline racks), replaces hand-coded rule functions with **generic type-based evaluators**, and generates a standalone **Pyvis rule network HTML** file.

## Key Design Decisions

- **No Excel parsing** — `!Scoring_Logic.md` is human-editable documentation. `Rules.py` has a mirrored Python `RULES` list (Option B).
- **Groups only, no sub-buildings** — each group is one block (or one polyline for racks).
- **Racks are polylines** (straight lines between two points), not rectangles.
- **Rule Type column** in `!Scoring_Logic.md` → maps 1:1 to generic functions in `Rules.py`.
- **Rule Network = standalone HTML** — saved to `Notes/Rule_Network.html`, opened in browser. Not embedded in dashboard.

## `!Scoring_Logic.md` ↔ `Rules.py` Connection

### New Table Format (with `Rule Type` column):

```markdown
| ID | Group | Rule Type | Target | Threshold | Penalty | Condition |
| PB-01 | Power Block | center_proximity | Plot Center | 20 m | 100 pts/m | excess beyond tolerance |
| CT-01 | Cooling Tower | windward_edge | Wind Direction | 30 m | 1000 pts | flat if not on edge |
| CT-02 | Cooling Tower | min_distance | Admin Building | 50 m | 500 pts/m | shortfall below threshold |
...
```

### Mirrored in `Rules.py`:

```python
RULES = [
    {"id": "PB-01", "type": "center_proximity", "group": "Power Block",    "target": "Plot Center",    "threshold": 20, "penalty_rate": 100,  "penalty_mode": "linear"},
    {"id": "CT-01", "type": "windward_edge",     "group": "Cooling Tower",  "target": "Wind Direction", "threshold": 30, "penalty_rate": 1000, "penalty_mode": "flat"},
    {"id": "CT-02", "type": "min_distance",      "group": "Cooling Tower",  "target": "Admin Building", "threshold": 50, "penalty_rate": 500,  "penalty_mode": "linear"},
    ...
]
```

### Available Rule Types:

| Rule Type | Function | What it checks |
|-----------|----------|---------------|
| `center_proximity` | `_eval_center_proximity()` | Distance from building center to plot center |
| `boundary_setback` | `_eval_boundary_setback()` | Min distance from any edge to site boundary |
| `windward_edge` | `_eval_windward_edge()` | Is building on the windward side? |
| `min_distance` | `_eval_min_distance()` | Center-to-center distance ≥ threshold |
| `max_distance` | `_eval_max_distance()` | Center-to-center distance ≤ threshold |
| `pipe_rack_proximity` | `_eval_pipe_rack_proximity()` | Distance from building to nearest rack line |
